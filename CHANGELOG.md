# Changelog

## Unreleased

This entry describes the development tree. No npm release or Git tag is recorded.

### Added

- Signature authentication for 21 provider IDs, with explicit provider selection.
- Express, Hono, Next.js and Cloudflare adapters, generated by the CLI.
- Static diagnostics, credential recipes and public API migration examples.
- Documentation checks, packed TypeScript consumers and generated-handler runtime checks.
- Optional offline comparisons against four pinned provider SDKs.

### Fixed

- Provider overview tables now list all 21 IDs and distinguish HMAC-SHA256,
  Vercel HMAC-SHA1 and fal Ed25519.
- Migration guidance describes fal credentials as top-level options.
- Qualification scripts check cleanup and file integrity before reporting success.

### Support boundaries

The package remains ESM-only, with Node.js 22 and 24 qualification. CommonJS is
an unshipped prototype. Verification preserves raw bytes and authenticates before
payload parsing. Linear authentication does not enforce freshness. Grafana needs
an explicit mode; Polar uses one key interpretation per verifier; fal uses
caller-trusted public keys and an expected account. SDK comparisons and local
runtime tests do not establish live-provider interoperability.

Queues, retries, business idempotency, JWKS retrieval and Relay are outside the
implemented core. Publication requires a separate maintainer decision.
